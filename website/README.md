# Daily Workspace homepage

Open `index.html` in any browser. The page is plain HTML with all CSS inside its `<style>` element; no framework, build step, or remote font service is required. A small inline script reveals panels on scroll; all content and links also work without JavaScript.

To host it, upload this directory with its `assets` folder to any static host. Keep the asset paths unchanged. The bundled Plus Jakarta Sans font is covered by `assets/FONT-LICENSE.txt`.

The install buttons currently point to the repository's setup instructions. When the add-on is published, replace the installation-guide link in the `get-started` section with the verified store URL and update its label.

The responsive bento layout includes entrance, hover, and FAQ animations. Reduced-motion preferences disable movement, including if the preference changes while the page is open.

Preview images use sample dashboard data. The website is separate from the extension; it does not replace the browser's New Tab page or enter the extension build.
